An Emacs configuration built on [[https://codeberg.org/ashton314/emacs-bedrock][emacs-bedrock]], targeting Emacs 31 (git master) with evil key bindings integrated.

* Features

- Evil mode key bindings for a Vim-like experience
- Modern completion stack: Corfu + Vertico + Embark
- Eglot (LSP) + Dape debugger for all-in-one development
- Tree-sitter support for major languages (Go / Rust / Python / JS, etc.)
- Deep Org-mode configuration + Elfeed RSS + mu4e email
- Dashboard startup screen + Tabspaces workspace management
- Magit Git integration + diff-hl highlights
- EMMS music player and Telega Telegram client
- Apheleia auto-formatting; no-littering keeps the directory clean
- Package archives default to USTC mirrors for fast installation in China

* Requirements

- Emacs 31 or later (git master)
- [[https://www.nerdfonts.com/][Nerd Font]] recommended (for icons)
- Optional: mpd (EMMS music), mu (email)

* Quick Start

** Installation

#+begin_src bash
git clone https://github.com/acdcbyl/.emacs.d.git ~/.emacs.d/
#+end_src

Dependencies are installed automatically on first launch. Emacs 31 git master is recommended for the best experience.

* Directory Structure

| File                    | Description                                        |
|-------------------------+----------------------------------------------------|
| ~early-init.el~         | Early initialization (GC, native-comp, UI trim)    |
| ~init.el~               | Main entry point, loads modules in order           |
| ~lisp/init-base.el~ etc | Base settings and feature modules                  |
| ~lisp/lang/~            | Language-specific configs (go/rust/python/js...)   |
| ~lisp/extension/~       | Self-maintained third-party packages (mu4e-nano..) |
| ~custom.el~             | Settings generated by =customize= (auto-generated) |

Main modules at a glance:

| Module             | Purpose         |
|--------------------+-----------------|
| init-completion.el | Completion      |
| init-dev.el        | LSP & dev       |
| init-check.el      | Syntax checking |
| init-dap.el        | Debugger        |
| init-diff.el       | Git/Diff        |
| init-project.el    | Project mgmt    |
| init-workspaces.el | Workspaces      |
| init-org.el        | Org-mode        |
| init-email.el      | Email (mu4e)    |
| init-feed.el       | RSS (Elfeed)    |
| init-emms.el       | Music (EMMS)    |
| init-telega.el     | Telegram        |
| init-dashboard.el  | Dashboard       |
| init-ui.el / theme | Appearance      |
